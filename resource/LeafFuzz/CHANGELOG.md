# Changelog

All notable changes to `LeafFuzz` are documented in this file.

## [0.1.0] - 2026-10-30

### Added
- Standalone multi-loader community QC, boundary fuzzer, post-GC memory-leak screener, and bytecode claim-delivery auditor deliverable (`LeafFuzz-0.1.0.jar`) supporting Paper, Spigot, Folia, Fabric, and NeoForge from a single archive (`ADR-125`, `ADR-126`, `leaffuzz-ADR-001`).
- Stage 1 Command & Least-Privilege Surface Auditor (`CommandSurfaceAuditor`, `BrigadierDispatcherInspector`, `PaperCommandTreeInspector`) inspecting live Brigadier and Bukkit command trees across `default` and `op` tiers, augmenting bare command roots with white-box bytecode subcommand and inline permission schemas (`BytecodeCausalGraphScanner.BytecodeCommandSchema`), folding `namespace:cmd` aliases, enforcing `DEFAULT_DENYLIST` (`stop`, `restart`, `op`, `deop`, `ban`, `kick`, `reload`), and generating ready-to-paste `commands.yml` and LuckPerms mitigations (`REQ-SLEUTH-FUZZ-002`).
- Stage 2 In-JVM Synthetic Persona Bot, GUI Menu & Swarm Boundary Fuzzer (`PersonaPolicyBotActor`, `SleuthServerFuzzer`, `LeafFuzzPaperEpisodeRunner`, `NmsEmbeddedPlayerSession`, `NodeBandit`, `FuzzActionShrinker`) evaluating the deterministic 256-byte `Int8[16x16]` `sleuth_persona_v1` policy genome (`selectPolicyActionInt` with Q10 `EXP2_FRAC_LUT`, 16 `POLICY_MICRO_SKILLS`, and 8 built-in archetypes plus optional `<rootFolder>/personas.jsonl` profiles) to drive player-only commands, salient GUI menu clicking (`hazard:gui-item-leak` icon extraction auditing), reversible world block micro-skills, concurrent player rosters dispersed across an Archimedean spiral (`players=auto` / `players=1..500`), and follow-up behaviors (`quit_lt1s`, `quit_delay`, `move`, `chunk_border_thrash`, `window_click`, `repeat`, `concurrent`) with Zeller's `ddmin` + binary numeric boundary bisection (`REQ-SLEUTH-FUZZ-004`).
- Stage 3 Main-Thread Stall, Synchronous Hazard & Exception Oracle (`LogAndStallSignatureOracle`, `JarClassOwnershipIndex`) attributing uncaught exceptions (`exc:`), slow-tick stalls (`stall:`), sub-100ms synchronous main-thread hazards (`hazard:sync-chunk:`, `hazard:sync-io:`, `hazard:blocking-wait:`), and grey-box thread coverage (`cov:`) outside GC pauses to the deepest plugin or mod `.jar` stack frame (`REQ-SLEUTH-FUZZ-001`, `REQ-SLEUTH-FUZZ-003`).
- Stage 4 Tick-Paced Post-GC Class Retention Screener (`ClassRetentionScreener`) capturing `DiagnosticCommandMBean#gcClassHistogram` snapshots off-thread (`S-005`) with an idle-control baseline (`qc-idle-control`) and candidate-scoped Bonferroni OLS regression across player departures and command executions.
- Stage 5 Zero-Classloading Bytecode & Config Causal Claim Delivery Auditor (`BytecodeCausalGraphScanner`, `LlmCausalChainAuditor`) verifying first-order (0-hop registration and YAML wiring, including `REGISTERED_CONFIG_GATED` vs `UNREGISTERED` listeners) and second-order ($k$-hop causal chains to terminal effect sinks, $k \le 4$) delivery (`Claims: <X> -> Does Not Deliver: <Y>`), corroborated with live Stage 2 telemetry and optional AST-grounded `Jminor` LLM fault explanations (`corpus-atlas-ADR-001`, `corpus-atlas-ADR-002`).
- Dual-purpose standalone external TCP swarm CLI (`LeafFuzzStandaloneCli`, `LeafFuzzTcpSwarmClient`) inside `LeafFuzz.jar` (`java -jar LeafFuzz.jar swarm --players auto` and `java -jar LeafFuzz.jar extract-mineflayer`).
- Canonical `CommandsAPI` command tree (`/fuzz`, `/leaffuzz`, `/qc`) with `name=value` parameter grammar (`commands-api-ADR-001`), multi-target selector support (`target=PluginA,PluginB` or `target=all`), stage selector (`stage=all|commands|fuzz|faults|leaks|claims|snapshot`), `/fuzz reset [scope=all|faults|leaks|campaign]`, interactive WCAG 2.1 parchment Book scorecard (`/fuzz report` via `LeafFuzzMenuBuilder` and `BookContrastValidator`), status-leading Markdown/YAML/JSON report export (`reports/<target>-qc-report.md`, `reports/<target>-qc-data.yml`, `reports/<target>-qc-data.json`), and `[FUZZ bit]` PBIT/CBIT/IBIT/LIVE self-tests (`/fuzz test`: `FUZZ-PBIT-001..002`, `FUZZ-CBIT-001..003`, `FUZZ-IBIT-001`, `FUZZ-LIVE-001..003`).
